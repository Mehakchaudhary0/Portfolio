About ME

I'm someone who enjoys both creativity and logic, which is why I am interested in Web Development and Data Analytics.

Web development allows me to design and build interactive and responsive websites, while data analytics enables me to work with data, analyze patterns, and find meaningful insights.

I'm currently a Computer Science undergraduate and have experience working with HTML, CSS, Tailwind, Javascript, SQL, Database Management, Excel, and programming languages - C, Python, Java.

I'm also exploring Data Science and Artificial Intelligence, where I am learning how data and technology can be used to solve real-world problems.

My goal is to continue learning, building projects, and developing my skills in data analytics, data science, and machine learning, while gaining practical experience through real-world projects.

Services

WEB DEVELOPMENT

I develop responsive and user-friendly websites using HTML, CSS, Tailwind CSS, and JavaScript. I focus on creating clean layouts, modern designs, and mobile-responsive websites that provide a good user experience. I enjoy turning ideas into real websites and continuously improving my frontend development and web design skills by building projects and learning new technologies

DATA ANALYTICS

I work with data to find meaningful insights and support decision-making. I use tools such as Excel, SQL, Power BI, and Python along with libraries like Pandas, NumPy, and Matplotlib to clean, organize, analyze, and visualize data. I am interested in understanding patterns in data, creating reports and dashboards, and solving real-world problems using data analytics and data visualization techniques.
